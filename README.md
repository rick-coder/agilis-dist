# Agilis — artefatos de distribuição

Este repositório público contém apenas os artefatos de distribuição da extensão
Agilis (Firefox), usados pelo mecanismo nativo de atualização.

- `updates.json` — manifesto lido pelo Firefox via `update_url`.
- **Releases** — XPI assinado pela Mozilla (canal unlisted).

O código-fonte permanece no repositório privado `rick-coder/agilis`.

## Instalação

1. Baixe o XPI assinado na release mais recente.
2. No Firefox: `about:addons` → engrenagem → **Instalar complemento de um arquivo…**
3. Confirme a instalação.

As versões seguintes são atualizadas automaticamente pelo Firefox.
